¿Cómo funciona?
Subí una factura PDF de Lopez Hnos.
• Si el código ya existe → suma el stock comprado + actualiza precio.
• Si no existe → crea el producto con el stock de la factura.
• El precio guardado es el precio neto de costo (unitario × (1 − descuento%)).
El stock importado se asignará a este local

📊 IMPORTAR EXCEL — LISTA PROVEEDOR
¿Cómo funciona?
El Excel debe tener columnas: SKU · Producto · Lista · PLAZO · PRONTO PAGO · Stock · Pedido
• Solo se importan filas donde la columna Pedido tiene un número.
• Ese número se usa como el stock a agregar.
• El precio que se guarda es el de la columna Lista (precio de costo).
El stock importado se asignará a este local

% MARGEN DE GANANCIA
Establecé el margen de ganancia para todos los productos del scope.
Precio venta = precio costo × (1 + margen% / 100)
Costo $1.000 + 40% → $1.400 · Cambiar a 50% → $1.500 (siempre desde el costo original)
⚡ Guarda el % en cada producto — igual que el margen individual pero masivo
